# swift-claw brand assets

Final selected visual identity for the swift-claw README and public release.

## Recommended repository placement

Copy this directory to:

`docs/assets/branding/`

Then paste the contents of `README-hero-snippet.md` at the top of `README.md`, above the badges.

## Files

- `swift-claw-hero-dark.png` — original 1774×887 master.
- `swift-claw-hero-dark-1400x700.png` — recommended README image.
- `swift-claw-hero-dark-1200x600.png` — smaller README/web export.
- `swift-claw-hero-dark-800x400.png` — compact documentation export.
- `swift-claw-social-card-1280x640.png` — social/Open Graph card.
- `swift-claw-mascot-transparent.png` — extracted mascot with transparency.
- `swift-claw-avatar-dark-512.png` — square avatar on a dark background.
- `swift-claw-avatar-light-512.png` — square avatar on a light background.
- `swift-claw-icon-transparent-256.png` — transparent compact icon.
- `swift-claw-wordmark-transparent.png` — wordmark only.
- `swift-claw-lockup-transparent.png` — complete transparent lockup.
- `README-hero-snippet.md` — ready-to-paste README markup.

## Notes

The transparent files are raster PNG exports derived from the approved final artwork.
For future print work, animation, or extensive resizing, recreate the mascot and wordmark
as true vector artwork in Figma, Illustrator, or another vector editor.
