# Page benchmark test-intent map

This is the pre-commit redundancy pass required by `docs/TESTING.md` §8.2 and §9.1. Every
retained test has one primary observable risk, a distinct reachable mutant, and a different nearest
test that would stay green for that mutant. Test data uses the protected source/gold corpus and the
real freeze manifest builder; synthetic copies of those contracts are not retained.
